Locked Mythical Kodan Caches are containers found by Warclaw in Janthir. They can be opened by using Kodan Cache Keys.

Acquisition

[edit]
  • Detected Treasure (chance)

Contents

[edit]
  • Mythical Kodan Cache (guaranteed)

Notes

[edit]
  • 1-3 can be acquired in Lowland Shore per day per account (varies based on map instance).
  • Only 1 can be acquired in Janthir Syntri per day per account.
  • Only 1 can be acquired in Mistburned Barrens per day per account.
  • The locations of the Caches are Map IP specific.
    • In a different instance (IP), a mythical cache cannot be dug up if it is in the same location of a cache that was already dug up.
