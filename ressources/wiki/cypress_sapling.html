Cypress Saplings are resource nodes found in level 70-80 areas. They can be logged at least 3 times.

Gathering results[edit]

  • If a Mithril or better logging axe is used
    • Elder Wood Log (1-2) (guaranteed)
    • Hidden Trove
    • Foxfire Cluster
    • Alpine Lumber Core (In the Shiverpeak Mountains)
    • Arid Lumber Core (In the Maguuma Wastes)
  • If a Mithril or better logging axe is not used
    • Ruined Log (guaranteed)
