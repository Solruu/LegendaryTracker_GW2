Legendary Relics: Components is a Legendary Trinkets achievement.

Achievement[edit]

Legendary Relics: Components Legendary Trinkets 0
Gather the necessary components and gifts for making a legendary relic. The wizard smith, Lyhr, can help you craft them in the Wizard's Tower.This collection can be a useful reference to what's needed for each gift. You may need multiples of some of these items.
