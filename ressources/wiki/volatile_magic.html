Rewarded by[edit]

  • Completing any of the following events:
    • Defeat the Legendary bounty (10)
    • Destroy the Mark III Suppressor Golem (5, 10)
    • Disable the Inquest security turrets (5-6, 10)
    • Engage Kralkatorrik (15)
    • Engage Kralkatorrik (30)
    • Help Elder Rhona track down the source of the storm (5-13)
  • Possible reward upon completing the group event Defeat the cache keeper (5-10).
  • Completing the raid Shiverpeaks Pass (300).
  • Completing any of the following maps:
    • Domain of Istan (100)
    • Sandswept Isles (100)

Other[edit]

  • Using roller beetle's boost ability to smash Volatile Crystals, scattered across Domain of Kourna. Requires Barrier Smash mastery.
  • Achieving map completion for any season 4 zone (a chance to reward map currency instead):
    • Domain of Istan
    • Sandswept Isles
    • Domain of Kourna
    • Jahai Bluffs
    • Thunderhead Peaks
    • Dragonfall
  • Completing dynamic events in the above zones—given as both a reward for individual events, and as a map bonus reward
  • Gathering while using an Volatile Harvesting Sickle, Volatile Logging Axe, Volatile Mining Pick or a gathering tool with a Glyph of Volatility applied.
