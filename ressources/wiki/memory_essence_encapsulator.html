Notes[edit]

  • One time use item. You need a total of 6 to complete the achievements.
  • If you have already unlocked a specific part of a collection, killing the same boss again with the item in your inventory does not consume another one.
  • Can be salvaged to return all of the items used to purchase it.
  • Will still trigger the associated achievements if stored in a shared inventory slot or in an invisible bag inventory slot.
