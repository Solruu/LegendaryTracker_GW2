Notes[edit]

  • This item is not unique; unlike most ascended trinkets, two of these can be equipped.
  • It is not possible to buy a non-infused version of this item; it is purchased pre-infused.
  • If you attune this item, the selected stats will reset, allowing you to choose new stats.
  • The chosen prefix for this item can be reset by using a Mist Capacitor.
