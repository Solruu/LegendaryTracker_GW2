# Cuir (Leather Sections) — dont Thick Leather Section

## Constat
Pas de "Dropped by" par créature ni par map, contrairement aux 8 trophées classiques
(`trophy_matrix` dans le tracker légendaire). Le cuir vient du **salvage** d'équipement,
qui n'est pas lié à un lieu précis.

## Source fiable
Salvager toute armure medium / objet de dos niveau 58-80. N'importe quel mob de ce niveau
peut faire tomber la pièce à salvager — pas de ciblage possible par map.

## Source "gratuite"
Les **Piece of (Common/—/Rare) Unidentified Gear** sont une source incidente, obtenue
juste en jouant (loot quasi universel niveau 80, foes/coffres/events partout). Identifier
avant de salvager (meilleur rendement que salvager directement). Rare uniquement :
liste de ~35 world bosses + 4 raids + 3 convergences qui la garantissent en complétion
(vs. centaines d'events "possible reward", trop diffus pour être exploitable) —
voir `gw2_sources_v203.json > meta_events` pour les timers déjà connus (Convergence
Mount Balrior/Outer Nayos, Ravenous Wanderer déjà dedans).

## Farm concret trouvé
**Lake Doric — "Leather farm" / "Uphill farm"** : train de squad avec commandant, cible
les champions centaures (Bloodstone-Warped Hide, Trumpeting Centaurs). Accès via LFG
→ Open World → Lake Doric. Rendement rapporté par la communauté (non officiel, à
vérifier en jeu) : T5 majoritaire, ~20-30 % T2-4, ~10 % T6 au salvage.
Source : guides communautaires (forum GW2, ~2017, toujours référencé dans les
compilations de farm récentes) — pas une donnée wiki officielle, patchs possibles depuis.

## Non retenu
Le "Gathered from" (33 % avec Glyph of the Leatherworker sur n'importe quel node
niveau 71-80) — écarté par choix (pas de glyphe spécialisé hors Unbound/Volatile Magic).
